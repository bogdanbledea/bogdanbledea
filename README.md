# Hi, I'm Bogdan

I build web apps and take care of the infrastructure they run on. I'm based in Timișoara, Romania.

By day I do full-stack, DevOps and infrastructure work at Haufe Group Romania. Most of what I write is React and Node.js, and most of it ends up running on AWS.

## What I work with

- **Frontend:** React, Vite, Tailwind
- **Backend:** Node.js, Express, TypeScript, Postgres
- **Infra:** AWS, Docker, Cloudflare, Kubernetes (k3s), Prometheus/Grafana/Loki
- **At home:** Home Assistant, Tailscale, Cloudflare Tunnel

## What I'm building

- **[adun.ro](https://adun.ro)**: a family budget app. It started life as a hackathon events platform and pivoted into something I actually use.
- **My home server:** I like taking matters into my own hands, so I run my own hardware instead of paying for hosting. A Dell Optiplex hosts my apps and a Raspberry Pi handles the home stuff, all connected over Tailscale. It's more work than clicking "deploy" somewhere, but I know exactly what's running and why.

## Mentoring

I've organized and mentored programs for university students, helping them go from "I know some code" to shipping a real full-stack app.
